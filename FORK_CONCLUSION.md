# Fork conclusion — what the morning search actually found

The control-law fork was created because the first artificial translation of Vollan-style focus was too arbitrary:

```text
high relevance
 -> faster theta
 -> less adaptation
 -> stronger anchor
```

Six computational forks were run instead.

## The main correction

The biological observation and the cellular implementation are different levels.

Vollan-like population behavior can be summarized by:

```text
stable reference
      +
movable sampling axis
      +
adjustable angular spread
      +
adjustable sampling rate
```

The experiments show that several different mechanisms can realize those population variables, and that directly changing a cellular parameter because it moves the same summary statistic is unsafe.

## The main engineering result

When a useful directional cue exists, a structured alternating sampler hedges cue error and provides high target coverage at very low internal path travel.

The best cheap attacker was not a neural attractor. It was a single deterministic state moving continuously between alternating side targets at a matched speed limit.

It achieved:

```text
reliable cue:    99.1% target-hit cycles
mixed cue:       83.9%
loss/reacquire:  0-ms measured reacquisition
travel:          ~0.010 rad/ms
```

IID random proposals were slightly better in coverage but moved ~0.32–0.40 rad/ms.

A smooth bounded random walk with ~0.014 rad/ms travel performed much worse.

Therefore the currently earned computational statement is:

> **Low-travel structured alternation can approximate the coverage benefit of random proposals much more efficiently than generic smooth motion.**

## What this does not establish

- that biological theta sweeps exist *for* this particular optimization criterion;
- that the Ji attractor is the best artificial implementation;
- that phase is required for the active-sensing result;
- that the directional control signal is generated by EC/HPC itself;
- that this beats ordinary attention, planning, search, or low-discrepancy methods on realistic AI tasks.

## How this reconnects to KyberDyyni

The strongest surviving architecture is now simpler than the biological inspiration:

```text
STABLE SLOW / REFERENCE STATE
           |
           +----------------------+
           |                      |
           v                      v
    fast control vector     structured sampler
    (salience / plan /      alternating low-travel
     memory / cue)                trajectory
           \                      /
            \                    /
             +---- sampled events
                       |
                 local address
                       |
                later consequence
                       |

```

Gate 2 on `main` remains the separate evidence that phase can provide an address for otherwise-indistinguishable within-sweep events.

Gate 5 on `main` remains the separate evidence that useful fast state can later become slow prior knowledge through delayed local consequence.

The fork adds a third independently earned piece:

> **the fast sampling process itself can be a structured, low-travel coverage mechanism.**

The next hard question is whether those three pieces become better together on a task where path, delayed credit, and repeated context all matter.
