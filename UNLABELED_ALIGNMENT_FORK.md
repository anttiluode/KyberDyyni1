# Unlabeled temporal alignment fork

Gate 10 showed that a low-rank slow correction can be re-rendered into an unseen basis once a few explicit cross-view correspondences are supplied.

Gate 11 removes those correspondence labels.

## Stronger setup

Two views contain the same **family of hidden freedoms**, but they are not synchronized samples of the same trajectory.

Each view gets its own independent trajectory generated by the same latent dynamics:

```text
latent process family
      |                   |
 independent run A   independent run B
      |                   |
    basis A             basis B
      |                   |
   stream A             stream B
```

There are no labels saying which state in A corresponds to which state in B.

The test asks whether a coordinate relation learned only from the streams can re-render a separate bank of hidden corrections from basis A into basis B.

## Two worlds

### Sawtooth dynamics

Four independent phase processes have approximately identical symmetric uniform marginals but different periods.

That matters:

- zero-lag variance does not identify component identity;
- marginal sign is ambiguous;
- autocorrelation profiles distinguish components;
- the direction of the sawtooth gives a **sign-sensitive temporal asymmetry** through the skew of increments.

### Gaussian AR dynamics

Four independent zero-mean Gaussian AR processes have equal unit variance but distinct autocorrelation time constants.

At any one instant the latent vector is an isotropic Gaussian. Static ICA has no privileged axes.

Temporal second-order statistics can identify axes and component identity, but the complete process is symmetric under a component sign flip. Therefore oriented vector transfer should retain a sign ambiguity.

This is a deliberate identifiability control, not a bug.

## Attackers

- PCA / zero-lag covariance;
- FastICA using only marginal statistics;
- FastICA axes plus temporal component matching;
- FastICA axes plus temporal matching and sign-sensitive increment orientation;
- multi-lag second-order temporal decomposition (SOBI-like operator);
- the same temporal decomposition with sign-sensitive temporal orientation;
- synchronized-time ridge as an upper attacker.

There is also a shuffled-time sawtooth control. If temporal alignment survives that, the experiment is wrong.

## Kill conditions

The strongest possible negative result is useful:

- if PCA/static ICA solve it, dynamics add nothing;
- if temporal methods recover axes but not oriented transfer, record the sign ambiguity rather than hiding it;
- if increment asymmetry solves sawtooth but FastICA plus the same temporal matching also solves it, do **not** claim SOBI is uniquely required;
- if shuffled time does not kill the temporal result, reject the result.

The architectural question is narrower than the algorithm name:

> **Can dynamics provide the missing correspondence information between changing coordinate systems?**
